# Groups inside groups, and scientific names

## Think first

You live in a village. The village is in a cell, the cell is in a sector, the sector is in a district, the district is in a province, and the province is in Rwanda. Which of these holds the most people? Which holds the fewest?

## Hierarchical classification

Living things are sorted in the same way: big groups are divided into smaller and smaller groups. This is called **hierarchical classification**.

There are seven levels, from the largest to the smallest:

- **Kingdom**
- **Phylum**
- **Class**
- **Order**
- **Family**
- **Genus**
- **Species**

A kingdom holds a huge number of different organisms. A species holds only organisms that are very closely related.

A **species** is a group of organisms that can breed with one another and produce offspring that can also reproduce.

To remember the order, use the first letters, K P C O F G S: **K**ind **P**eople **C**an **O**ften **F**ind **G**ood **S**olutions.

## Why common names are a problem

The same animal has different names in different languages: inka, cow, vache. Scientists in different countries need one name that everyone understands.

## The binomial system

A biologist called **Linnaeus** developed a system that gives every organism **two Latin names**. It is called the **binomial system**. "Bi" means two.

- The first name is the **genus**.
- The second name is the **species**.

Examples: a human is *Homo sapiens*, a cow is *Bos taurus*, a lion is *Panthera leo* and a honeybee is *Apis mellifera*.

## How to write a scientific name

- The genus name starts with a **capital letter**.
- The species name starts with a **small letter**.
- In print, the name is in italics. By hand, underline each of the two words separately.

## Example

Is "bos Taurus" written correctly?

- The genus must have the capital letter, and the species must not.
- The correct name is *Bos taurus*.
