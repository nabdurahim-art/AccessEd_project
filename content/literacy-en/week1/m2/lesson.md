# Building short words

Join letter sounds together to make a word. Say each sound, then say them fast.

- b + a + g = **bag**
- m + a + p = **map**
- p + i + g = **pig**
- h + o + t = **hot**

## Word families

Change only the first letter and you get a new word. These words all end in **-at**:

- cat
- hat
- mat
- sat

Practise: say each word, then write it on paper.
